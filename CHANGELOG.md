## [1.0.0] - 2026-11-19

The first release: agent skills for building on the QIE blockchain, as plain Markdown. Install them with `npx skills add Archzxylabs/qie-forge`.

### Added

- Nine skills:
  - `qie`, the router;
  - `qie-networks`, `qie-concepts`, `qie-addresses`, `qie-scaffold`, `qie-wallet-integration`, `qie-transactions` and `qie-debug`;
  - `qie-ecosystem`, with five reference files.
- Sourced facts, each labelled Documented, Observed, Claimed or Unknown. Observations were taken on 2026-11-16 and re-verified on 2026-11-17.
- A dependency-free CI check for skill frontmatter, router coverage, relative links and local paths.
- The MIT License, a contributing guide, a security policy, a code of conduct, issue forms and a pull request template.
