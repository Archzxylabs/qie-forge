## 2. Invariants & Negative Evidence Findings

1. **Unpublished npm packages**: Both `qie-lend-sdk` and `qusdc-sdk` exist as GitHub repositories under `qieadmin`, but neither is published to the npm registry. Coding agents must not advise `npm install`.
2. **Indexer coverage is unsubstantiated, not proven absent**: No QIE indexer deployment (The Graph Hosted Service/Network, Envio HyperIndex, SubQuery, or Goldsky) was located **in the sources reviewed for this release**, so `indexer-query` stays `UNKNOWN`. `UNKNOWN` is an evidence state, not proof that no deployment exists; unreviewed or newly launched deployments may exist. Programmatic querying may fall back to direct bounded `eth_getLogs`, whose provider-specific limits are unmeasured.
3. **Empty Address Collection**: Despite source-claimed addresses in S12 (Oracle) and S16 (asset list), `knowledge/addresses.yaml` remains `[]` because identity observations (`checkAddresses`) have not been conducted. An explorer page, source-verified listing, or nonempty bytecode never establishes issuer identity, ABI correspondence, or product ownership; no address is published or recommended.
4. **Legacy Chain ID Conflicts**: Pre-V3 chain IDs 5656 and 9731 are documented as deprecated. Third-party aggregators showing 5656 represent a conflict resolved in favor of canonical V3 Chain ID 1990.
5. **No fixed operational parameters are published**: This release publishes no fixed native staking fee, no `eth_getLogs` block-range limit, and no gas defaults. Such values are live network facts that have never been measured here.
